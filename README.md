# smitosrt
smi to srt conversion

필요로 의해 직접 만든 SMI → SRT 자막 일괄 변환기 (Windows)

## 받는 방법

[Releases](../../releases/latest) 에서 `SmiToSrtConverter-1.2.1-win-x86.zip` 을 받아 압축을 풀고 `SmiToSrtConverter.exe` 를 실행하면 됩니다. 설치는 필요 없습니다.

## 기능

- 여러 SMI 파일을 한 번에 변환 (끌어다 놓기 지원)
- 인코딩 자동 판별 (UTF-8, CP949/EUC-KR, UTF-16, UTF-32). 글자가 깨지면 직접 골라 다시 변환
- 한국어 우선 변환. 필요하면 언어별로 나누거나 모든 언어를 합쳐서 변환
- 기울임, 굵게, 밑줄, 글자색 유지
- 같은 이름의 SRT 가 이미 있으면 덮어쓰기 전에 확인
